# Documentos obsoletos

Estos archivos describen una versión anterior de la plataforma ("Fotografos Platform", `api.fotografos.com`, API v1.0.0) y **ya no son
correctos**. Se conservan solo como referencia histórica; no los entregues a clientes.

La documentación vigente de la API pública para empresas está en `docs/partner/` y `docs/partner-openapi.yaml`
(se regenera con `npm run docs:partner`).
